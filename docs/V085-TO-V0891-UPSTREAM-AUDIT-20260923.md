## Current final-test boundary

Keep the current non-Reno candidate's tested v0.8.5 + NRSTAB/ShadowFloor + exposure/multi-mip + selected NR/FG hardening contents stable for a Miles FG-off/on and NRSTAB-off/on A/B. The upstream release's own notes say live-game preview and RTX40 hardware verification were not performed. CPU/WARP tests and a successful Release build do not establish absence of FG smearing.

Useful next ports should be independent commits with failure tests before production edits. v0.8.6 and v0.8.7 are safety priorities; v0.8.8 is a visual-quality option. Spatial compression and the v0.8.91 preview are one separate experimental track. None should be inferred to fix the earlier FG smear without a controlled game test.
